## Important data limitation

The CSV files currently committed in the Week 1 repository were generated by the project's data-generation script. They are **synthetic demonstration data**, not verified customer or transaction records from a real salon. They can be used to demonstrate data preparation and analysis code, but they must not be described as actual salon observations. A real causal estimate requires authorised first-party experiment assignment, booking, visit, point-of-sale, customer-history, and stylist-capacity data.

Public sources listed in the register provide industry or external context. They cannot identify which salon customer was assigned to the recommendation treatment and cannot replace first-party treatment and outcome records.

## Reproducibility and privacy

- Record the source URL, extraction date, date range, and data version for each input.
- Keep raw source extracts unchanged; write cleaned outputs to separate folders.
- Use pseudonymous customer identifiers in analysis datasets. Do not commit names, phone numbers, email addresses, or other direct identifiers.
- Record software/package versions and random seeds for reproducible analysis.
- Confirm the source's licence, API terms, and permitted use before downloading or redistributing data.

## Status

This is a **data sourcing and analysis plan**. It does not claim that real salon data has been acquired, that all proposed APIs have been accessed, or that the proposed CUPED / DiD diagnostics have already been executed on real data.
